# INDIGO Landing Page

Welcome to the **INDIGO Landing Page** — a vibrant, immersive, and interactive platform that connects local artists with the community. This project combines dynamic visuals, smooth animations, and engaging UI elements to reflect the spirit of artistic collaboration.

---

## 🎨 Design

The design concepts were created with the help of **Figma AI**, based on original ideas and creative direction by **Karol Díaz**. Figma was used as a tool to visualize concepts, while all design decisions, layouts, and assets are original.  

Original Figma reference: [Design INDIGO Landing Page](https://www.figma.com/design/CfC3DMqnEgT7nIHZVi9Bc3/Design-INDIGO-Landing-Page)

---

## 🚀 Features

- Fully responsive design for desktop and mobile.
- Animated hero section with GIF background, spotlight beams, and ambient music.
- Smooth scrolling navigation to explore categories.
- CTA buttons for "Explore Categories" and "Join as Artist" (link to Google Form).
- Social contact section with WhatsApp, Instagram, and Facebook links.
- Footer with platform info and creator attribution.

---

## 🛠 Technology Stack

- **Frontend:** React, TailwindCSS, Framer Motion
- **Icons:** Lucide React, React Icons
- **Design Tool:** Figma (Figma AI assisted concept generation)
